# snowkei.github.io

Personal site of **Snowkei** — hand-written HTML, CSS and a little JavaScript. No framework, no trackers.

- `index.html` — single page
- `assets/style.css` — design tokens, dark & light themes
- `assets/main.js` — language (中 / EN) and theme toggle
- `assets/mark.svg` — site mark

Live at <https://snowkei.github.io>.
